[stderr] ## Reading From FRange
[stderr] 
[stderr] Get a range from `sheet.getRange(...)`, then use these reads:
[stderr] 
[stderr] - `getValue() -> any` - get the top-left cell value as the normal displayed value
[stderr] - `getRawValue() -> any` - get the top-left cell raw underlying value
[stderr] - `getValues() -> any[][]` - get all cell values in the range as a 2D array
[stderr] - `getRawValues() -> any[][]` - get all underlying raw values in the range as a 2D array
[stderr] - `getFormulas() -> string[][]` - get formulas in A1 notation
[stderr] - `getA1Notation(withSheet?) -> string` - get the range A1 notation; `withSheet=true` includes the sheet name
[stderr] - `forEach(callback) -> void` - iterate cells in the range
[stderr] - `isMerged() -> boolean` - check whether the range itself is merged
[stderr] - `isPartOfMerge() -> boolean` - check whether the range falls inside a merged region
[stderr] 
[stderr] Example:

[stderr] ## setValues() Shape Rules
[stderr] 
[stderr] `setValues()` expects a rectangular 2D array whose shape matches the target range:
[stderr] 
[stderr] - one row per worksheet row in the target range
[stderr] - one column per worksheet column in the target range
[stderr] - keep every inner array the same length
[stderr] - use `getRange('A1:C10')` or `getRange(0, 0, 10, 3)` to define the full target shape
[stderr] - `getRange(row, col)` without size only targets a single cell

[stderr] Correct:
[stderr] 
[stderr] ```javascript
[stderr] sheet.getRange("A1:B2").setValues([
[stderr]   ["Name", "Score"],

[stderr] ```

[stderr] Incorrect shape:
[stderr] 
[stderr] ```javascript
[stderr] sheet.getRange("A1:B2").setValues([["Name"], ["Ada", 95, "extra"]]);

[stderr] Merge APIs:
[stderr] 
[stderr] - `merge(options?) -> void` - merge cells into one block

[stderr] 
[stderr] ```javascript

[stderr] 
[stderr] Use `autoFill()` when a correct seed pattern already exists and the workbook should propagate it.
