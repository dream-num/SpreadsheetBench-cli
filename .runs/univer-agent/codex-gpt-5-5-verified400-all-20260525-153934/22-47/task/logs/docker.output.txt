[stderr] ### Create Or Maintain Charts
[stderr] 
[stderr] Use `univer run` for workbook-local charts and `univer view` for visual inspection. Command-line verification should read facade state such as `sheet.getCharts()`, `chart.getChartId()`, `chart.getRange()`, `chart.getSeriesData()`, and `chart.getCategoryData()`.
[stderr] 
[stderr] ```bash
[stderr] univer help run charts
[stderr] univer run "$WB" --file ./create-chart.js
[stderr] univer view "$WB" --no-open --json
[stderr] ```
[stderr] 
[stderr] In scripts, seed or choose a source range, configure `sheet.newChart()`, call `build()`, then insert it with `sheet.insertChart(chartInfo)`. Use `chart.updateRange()` or `sheet.removeChart(chart)` for maintenance.
[stderr] 
[stderr] Special chart types have stricter source shapes:
[stderr] 
[stderr] - Most charts use a category-plus-series table, for example `month, sales, cost`.
[stderr] - Relation charts require a node/type matrix: first column is node, second column is type/category, remaining columns are the numeric relation matrix. For `N` nodes, use `N` data rows and `N + 2` columns.
[stderr] - Sankey charts require a `source, target, value` edge list. The third column must be numeric; avoid reverse edges that create circular Sankey data.
[stderr] - Bubble charts need numeric `x`, `y`, and `size` columns.
[stderr] - Heatmap charts use the first column as y-axis labels, remaining headers as x-axis labels, and remaining cells as numeric heat values.

[stderr] ### Create Or Maintain Shapes
[stderr] 
[stderr] Use `univer run` for workbook-local shapes and connectors and `univer view` for visual inspection. [stderr] ```bash
[stderr] univer help run shapes
[stderr] univer run "$WB" --file ./create-shapes.js
[stderr] univer view "$WB" --no-open --json
[stderr] ```
[stderr] 
[stderr] In scripts, configure `sheet.newShape()`, call `build()`, then insert it with `sheet.insertShape(shapeInfo)`. Use `sheet.newConnector()` for connector lines, `sheet.connectShapes()` to attach connector endpoints to facade shape objects from the same worksheet, `sheet.newShape(existingShape)` with `sheet.updateShape(updatedShapeInfo)` for updates, and `sheet.removeShape(shape)` for deletion.

[stderr] ### Version Verified Changes
[stderr] 
[stderr] Check status before committing. Commit only after workbook-visible verification.
[stderr] 
[stderr] ```bash
[stderr] univer status "$WB"
[stderr] univer commit "$WB" --message "Update review ranges"
[stderr] univer status "$WB"
[stderr] ```
[stderr] 
[stderr] `commit` creates a local changeset from current local mutations. It does not push to a remote.
[stderr] 
[stderr] Use `restore` when current uncommitted workbook mutations should be discarded while preserving local commits and synced history.
[stderr] 
[stderr] ```bash
[stderr] univer status "$WB"
[stderr] univer restore "$WB"
[stderr] univer status "$WB"
[stderr] ```
[stderr] 
[stderr] Use `reset --soft HEAD~N` to remove the last N local unsynced commits and restore their mutations as uncommitted local mutations. Use `reset --hard HEAD~N` to remove the last N local unsynced commits and discard current uncommitted local mutations.
[stderr] 
[stderr] ```bash
[stderr] univer status "$WB"
[stderr] univer reset "$WB" --soft HEAD~1
[stderr] univer status "$WB"
[stderr] 
[stderr] univer reset "$WB" --hard HEAD~1
[stderr] univer status "$WB"
[stderr] ```
[stderr] 
[stderr] `reset` only accepts `HEAD~N` targets and only operates on local unsynced commits. It does not rewrite synced changesets or remote history.
[stderr] 
[stderr] ### Clone, Pull, And Sync
[stderr] 
[stderr] Use `clone` when a remote workbook unit already exists and you need a new local package path. The target `.univer` path must be nonexistent or empty.
[stderr] 
[stderr] ```bash
[stderr] WB=./budget.univer
[stderr] univer clone "$WB" --unit-id unit-remote --json
[stderr] univer status "$WB"
[stderr] univer inspect workbook "$WB"
[stderr] ```
[stderr] 
[stderr] Use `pull` when you only need missing remote changesets for a package already bound to a remote unit. Use `sync` to sync local and remote versioning state.
[stderr] 
[stderr] ```bash
[stderr] univer status "$WB"
[stderr] univer pull "$WB"
[stderr] univer status "$WB"
[stderr] 
[stderr] univer commit "$WB" --message "Update review ranges"
[stderr] univer sync "$WB"
[stderr] univer status "$WB"
[stderr] ```
[stderr] 
[stderr] `sync` creates the remote workbook first when the package is still local-only. It pulls remote changes and pushes local changesets, but it does not push uncommitted local mutations. Remote endpoints come from `collaboration.defaultRemote` and `collaboration.remotes.<name>.url`.

[stderr] ## Gotchas
[stderr] 
[stderr] - `manifest.json` is metadata only. It does not prove sheet names, formulas, changed cells, or handoff correctness.
[stderr] - Package contents are not a meaningful way to infer spreadsheet data. Use public CLI reads instead.
[stderr] - Local file identity is the workbook path, such as `./budget.univer`, not `unitId`, `sessionId`, or manifest ids.
[stderr] - Command success is not enough after import, mutation, export, or handoff. Verify workbook-visible state.
[stderr] - A non-zero exit means the operation failed. Read stderr for the diagnostic, usage, and retry guidance.
[stderr] - `search` may be unavailable or limited in some installed versions. Fall back to bounded `inspect range`.
[stderr] - Quote the full range: `--range 'Sheet1!A1:J20'`, not just the sheet name fragment.
[stderr] - Shell row counts can pass while headers, columns, or keys shift. Check headers, samples, and key columns together.
[stderr] - `pipe in` writes parsed matrix data and reports a summary; it does not echo input.
[stderr] - `view` is readonly preview. Do not treat it as mutation verification unless the task is visual review.
[stderr] - Charts are maintained through `univer run` and the Pro Charts facade. Do not edit chart resource internals or expect `run` to export chart images.
[stderr] - Shapes are maintained through `univer run` and the Pro Shapes facade. Do not inspect private drawing resource storage or expect `run` to export shape images.
[stderr] - Floating images are maintained through `univer run` and the Sheets Drawing facade. Do not invent a top-level `univer image` command or inspect private drawing resource storage.
[stderr] - `commit` is local only; use `sync` to push local changesets.
[stderr] - `restore` discards only uncommitted local mutations; it does not remove local commits.
[stderr] - `reset` is local-only and limited to `HEAD~N` over unsynced local commits. Do not use it as a remote revert or force-push workflow.
[stderr] - `sync` does not push uncommitted local mutations. Commit verified workbook changes first.
[stderr] - If `sync` reports an invalid remote binding, stop and diagnose the package or remote setup.
[stderr] - `pull` requires a package already bound to a remote unit. Use `sync` for first remote creation or `clone --unit-id` for an existing remote unit.
[stderr] - `clone` replaced older remote binding wording. Do not use or invent a `bind` command.
[stderr] - If runtime-backed commands fail to start, inspect `univer daemon status` before retrying blindly.
[stderr] - If workbook-visible reads disagree with package metadata, trust workbook-visible reads first.
