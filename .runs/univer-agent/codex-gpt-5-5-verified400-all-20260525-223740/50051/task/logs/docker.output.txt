[stderr] # univer-cli
[stderr] 
[stderr] `univer` is a spreadsheet engine in the terminal. Use it when an agent needs real workbook semantics: sheets, ranges, formulas, formatting, layout, previews, imports, exports, or versioned workbook state.
[stderr] 
[stderr] Install the CLI with `npm i -g univer-cli`. Update the CLI with `univer update`. The executable is `univer`; `unv` may be available as a short alias.
[stderr] 
[stderr] ## Core Mental Model
[stderr] 
[stderr] Treat workbook-visible state as the source of truth. A successful command summary, package metadata, or an internal manifest does not prove that sheet names, cell values, formulas, formatting, or exported handoff files are correct.
[stderr] 
[stderr] The workbook path is the local identity. Pick one explicit path such as `./budget.univer` and use that path as the CLI target. Do not target workbooks by `unitId`, `sessionId`, manifest ids, or runtime ids.
[stderr] 
[stderr] `.univer` and `.unv` files are CLI operation targets, not agent-editable data stores. Read and write workbook data through public CLI surfaces such as `inspect`, `search`, `pipe`, `run`, `export`, `status`, and `commit`.
[stderr] 
[stderr] Use `univer help` and `univer help <command...>` for exact syntax. For `run` scripts, use `univer help run` and `univer help run <topic>` before relying on unfamiliar APIs.
[stderr]

[stderr] # Ranges
[stderr] 
[stderr] This topic groups cell and range operations for ordinary `run` tasks.
[stderr] 
[stderr] ## Reading From FRange
[stderr] 
[stderr] Get a range from `sheet.getRange(...)`, then use these reads:
[stderr] 
[stderr] - `getValue() -> any` - get the top-left cell value as the normal displayed value
[stderr] - `getRawValue() -> any` - get the top-left cell raw underlying value
[stderr] - `getValues() -> any[][]` - get all cell values in the range as a 2D array
[stderr] - `getRawValues() -> any[][]` - get all underlying raw values in the range as a 2D array
[stderr] - `getFormulas() -> string[][]` - get formulas in A1 notation
[stderr] - `getA1Notation(withSheet?) -> string` - get the range A1 notation; `withSheet=true` includes the sheet name
[stderr] - `forEach(callback) -> void` - iterate cells in the range
[stderr] - `isMerged() -> boolean` - check whether the range itself is merged
[stderr] - `isPartOfMerge() -> boolean` - check whether the range falls inside a merged region
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sales");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sales" not found' };
[stderr] 
[stderr]   const range = sheet.getRange("A1:C3");
[stderr]   return {
[stderr]     success: true,
[stderr]     a1: range.getA1Notation(),
[stderr]     values: range.getValues(),
[stderr]     formulas: range.getFormulas()
[stderr]   };
[stderr] };
[stderr] ```
[stderr] 
[stderr] ## Writing To FRange
[stderr] 
[stderr] Core writes:
[stderr] 
[stderr] - `setValue(value) -> FRange` - set one value across the target range; if the value starts with `=`, it can also write a formula
[stderr] - `setValues(values) -> FRange` - batch set values from a 2D array
[stderr] - `setFormula(formula) -> void` - set a formula in A1 notation such as `=SUM(A1:B10)`
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sheet1");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sheet1" not found' };
[stderr] 
[stderr]   sheet.getRange("A1").setValue("Total");
[stderr]   sheet.getRange("B2:C3").setValues([
[stderr]     [10, 20],
[stderr]     [30, 40]
[stderr]   ]);
[stderr] 
[stderr]   return { success: true };
[stderr] };
[stderr] ```
[stderr] 
[stderr] ## setValues() Shape Rules
[stderr] 
[stderr] `setValues()` expects a rectangular 2D array whose shape matches the target range:
[stderr] 
[stderr] - one row per worksheet row in the target range
[stderr] - one column per worksheet column in the target range
[stderr] - keep every inner array the same length
[stderr] - use `getRange('A1:C10')` or `getRange(0, 0, 10, 3)` to define the full target shape
[stderr] - `getRange(row, col)` without size only targets a single cell
[stderr] 
[stderr] Correct:
[stderr] 
[stderr] ```javascript
[stderr] sheet.getRange("A1:B2").setValues([
[stderr]   ["Name", "Score"],
[stderr]   ["Ada", 95]
[stderr] ]);
[stderr] ```
[stderr] 
[stderr] Incorrect shape:
[stderr] 
[stderr] ```javascript
[stderr] sheet.getRange("A1:B2").setValues([["Name"], ["Ada", 95, "extra"]]);
[stderr] ```
[stderr] 
[stderr] When writing a single cell, use `setValue()` unless the task specifically benefits from 2D shape handling.
[stderr] 
[stderr] ## Formulas And Async Readback
[stderr] 
[stderr] Formula calculation is asynchronous. This applies to:
[stderr] 
[stderr] - `range.setFormula('=SUM(B1:B10)')`
[stderr] - `range.setValue('=SUM(B1:B10)')`
[stderr] 
[stderr] If you need the calculated result in the same `run`, wait for formula application:
[stderr] 
[stderr] ```javascript
[stderr] async () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sales");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sales" not found' };
[stderr] 
[stderr]   sheet.getRange("A1").setFormula("=SUM(B1:B10)");
[stderr]   await univerAPI.getFormula().onCalculationResultApplied();
[stderr] 
[stderr]   return {
[stderr]     success: true,
[stderr]     value: sheet.getRange("A1").getValue()
[stderr]   };
[stderr] };
[stderr] ```
[stderr] 
[stderr] Available formula wait API:
[stderr] 
[stderr] - `univerAPI.getFormula() -> FFormula`
[stderr] - `onCalculationResultApplied() -> Promise<void>` - wait for formula-calculation results to be applied before reading the computed value
[stderr] 
[stderr] ## Merge And Unmerge
[stderr] 
[stderr] Merge APIs:
[stderr] 
[stderr] - `merge(options?) -> void` - merge cells into one block
[stderr] - `breakApart() -> void` - unmerge cells
[stderr] - `mergeAcross() -> void` - merge each row across the selected columns
[stderr] - `mergeVertically() -> void` - merge each column down the selected rows
[stderr] 
[stderr] Typical uses:
[stderr] 
[stderr] - `merge()` for one combined block
[stderr] - `mergeAcross()` to merge each row across the selected columns
[stderr] - `mergeVertically()` to merge each column down the selected rows
[stderr] - `breakApart()` to remove merges
[stderr] - use `merge({ isForceMerge: true })` if you need to clear overlapping merges first
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Report");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Report" not found' };
[stderr] 
[stderr]   sheet.getRange("A1:D1").merge();
[stderr]   sheet.getRange("A3:D4").mergeAcross();
[stderr] 
[stderr]   return {
[stderr]     success: true,
[stderr]     titleMerged: sheet.getRange("A1").isPartOfMerge()
[stderr]   };
[stderr] };
[stderr] ```

[stderr] 
[stderr] Use `autoFill()` when a correct seed pattern already exists and the workbook should propagate it.
[stderr] 
[stderr] - `autoFill(destRange, fillType?) -> Promise<void>` - propagate from the source range into a larger destination that includes the source

[stderr] Notes:
[stderr] 
[stderr] - `destRange` must include the source range
[stderr] - `fillType` can be `'SERIES'` (default) or `'COPY'`
[stderr] - this method is async; use `await`
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript

[stderr]   const workbook = univerAPI.getActiveWorkbook();

[stderr] 
[stderr]   return { success: true, values: dest.getValues() };
[stderr] };
[stderr] ```

[stderr] # Formulas
[stderr] 
[stderr] This topic focuses on formula writes, calculation waits, and readback behavior inside `run`.
[stderr] 
[stderr] ## What This Topic Is For
[stderr] 
[stderr] Use this topic when the task needs workbook-native recalculation and the result must remain consistent with how the workbook computes formulas.
[stderr] 
[stderr] ## Formula Writes
[stderr] 
[stderr] You can write formulas with either of these APIs:
[stderr] 
[stderr] - `setFormula(formula) -> void`
[stderr] - `setValue(value) -> FRange` when `value` starts with `=`
[stderr] 
[stderr] This applies to both:
[stderr] 
[stderr] - `range.setFormula('=SUM(B1:B10)')`
[stderr] - `range.setValue('=SUM(B1:B10)')`
[stderr] 
[stderr] ## Formula Calculation
[stderr] 
[stderr] Formula calculation is asynchronous. If you need the calculated result in the same `run`, wait for calculation to finish:
[stderr] 
[stderr] ```javascript
[stderr] await univerAPI.getFormula().onCalculationResultApplied();
[stderr] ```
[stderr] 
[stderr] Available formula wait API:
[stderr] 
[stderr] - `univerAPI.getFormula() -> FFormula`
[stderr] - `onCalculationResultApplied() -> Promise<void>` - wait for formula-calculation results to be applied before reading the computed value
[stderr] - note: if a real calculation runs, it resolves when results are applied; if no calculation starts quickly, it can resolve automatically instead of hanging forever
[stderr] 
[stderr] ## Formula Warning
[stderr] 
[stderr] Without the wait, readback can be stale.
[stderr] 
[stderr] ## Copyable Example
[stderr] 
[stderr] ```javascript
[stderr] async () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sales");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sales" not found' };
[stderr] 
[stderr]   sheet.getRange("A1").setFormula("=SUM(B1:B10)");
[stderr]   await univerAPI.getFormula().onCalculationResultApplied();
[stderr] 
[stderr]   return {
[stderr]     success: true,
[stderr]     formula: sheet.getRange("A1").getFormulas(),
[stderr]     value: sheet.getRange("A1").getValue()
[stderr]   };
[stderr] };
[stderr] ```
[stderr] 
[stderr] ## Formula Readback With setValue()
[stderr] 
[stderr] ```javascript
[stderr] async () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sales");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sales" not found' };

[stderr] # Core
[stderr] 
[stderr] This topic groups the workbook, worksheet, and structural APIs behind most `run` tasks.
[stderr] 
[stderr] ## Object Hierarchy
[stderr] 
[stderr] ```text
[stderr] univerAPI
[stderr]   -> getActiveWorkbook() -> FWorkbook
[stderr]     -> getSheetByName(name) -> FWorksheet | null
[stderr]       -> getRange(...) -> FRange
[stderr] ```
[stderr] 
[stderr] ## Entry Point
[stderr] 
[stderr] Start from the active workbook:
[stderr] 
[stderr] ```javascript
[stderr] const workbook = univerAPI.getActiveWorkbook();
[stderr] ```
[stderr] 
[stderr] Top-level APIs used most often:
[stderr] 
[stderr] - `univerAPI.getActiveWorkbook() -> FWorkbook` - get the current active workbook
[stderr] - `univerAPI.getFormula() -> FFormula` - get the formula engine instance used for calculation synchronization
[stderr] 
[stderr] Dimension constants used by `insertCells()` and `deleteCells()`:
[stderr] 
[stderr] - `univerAPI.Enum.Dimension.ROWS` - row dimension constant for `insertCells()` and `deleteCells()`
[stderr] - `univerAPI.Enum.Dimension.COLUMNS` - column dimension constant for `insertCells()` and `deleteCells()`
[stderr] 
[stderr] ## Workbook And Worksheet Access
[stderr] 
[stderr] Use the workbook object to locate, list, create, and delete sheets.
[stderr] 
[stderr] - `getSheetByName(name) -> FWorksheet | null` - recommended explicit lookup by sheet name
[stderr] - `getSheets() -> FWorksheet[]` - list all worksheets; useful when the task first needs sheet names
[stderr] - `create(name, rows, cols) -> FWorksheet` - create a new worksheet with an initial shape
[stderr] - `deleteSheet(sheetId) -> boolean` - delete the specified worksheet by sheet id
[stderr] 
[stderr] Common worksheet reads:
[stderr] 
[stderr] - `getSheetId() -> number`
[stderr] - `getSheetName() -> string`
[stderr] - `getLastRow() -> number` - 0-based index of the last row with data
[stderr] - `getLastColumn() -> number` - 0-based index of the last column with data
[stderr] - `hasHiddenGridLines() -> boolean`
[stderr] 
[stderr] Common worksheet writes:
[stderr] 
[stderr] - `setName(name) -> void`
[stderr] - `insertRows(rowIndex, numRows) -> FWorksheet`
[stderr] - `deleteRows(rowIndex, numRows) -> FWorksheet`
[stderr] - `insertColumns(columnIndex, numColumns) -> FWorksheet`
[stderr] - `deleteColumns(columnIndex, numColumns) -> FWorksheet`
[stderr] - `setFrozenRows(rows)` or `setFrozenRows(startRow, endRow) -> FWorksheet`
[stderr] - `setFrozenColumns(columns)` or `setFrozenColumns(startColumn, endColumn) -> FWorksheet`
[stderr] - `setHiddenGridlines(hidden) -> FWorksheet`
[stderr] - `setGridLinesColor(color) -> FWorksheet` - `undefined` or `null` resets to default
[stderr] - `setRowHeight(rowIndex, height) -> FWorksheet`
[stderr] - `setRowHeights(startRow, numRows, height) -> FWorksheet`
[stderr] - `showRows(rowIndex, numRows) -> FWorksheet`
[stderr] - `hideRows(rowIndex, numRows) -> FWorksheet`
[stderr] - `autoResizeRows(startRow, numRows) -> FWorksheet`
[stderr] - `setColumnWidth(columnIndex, width) -> FWorksheet`
[stderr] - `setColumnWidths(startColumn, numColumns, width) -> FWorksheet`
[stderr] - `showColumns(columnIndex, numColumns) -> FWorksheet`
[stderr] - `hideColumns(columnIndex, numColumns) -> FWorksheet`
[stderr] - `autoResizeColumns(startColumn, numColumns) -> FWorksheet`

[stderr] 
[stderr] ```javascript

[stderr] ## getRange()
[stderr] 
[stderr] `getRange()` is the standard bridge from a worksheet to cell-level work.
[stderr] 
[stderr] Supported forms:
[stderr] 
[stderr] - `getRange('A1')`
[stderr] - `getRange('A1:C10')`
[stderr] - `getRange('A:A')`
[stderr] - `getRange('1:1')`
[stderr] - `getRange(row, col)`
[stderr] - `getRange(row, col, rowCount, colCount)`
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sales");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sales" not found' };
[stderr] 
[stderr]   const header = sheet.getRange("A1:C1").getValues();
[stderr]   const firstCell = sheet.getRange(0, 0).getValue();
[stderr] 
[stderr]   return { success: true, header, firstCell };
[stderr] };
[stderr] ```
[stderr] 
[stderr] ## Coordinate Model
[stderr] 
[stderr] Numeric coordinates are 0-based:
[stderr] 
[stderr] - `getRange(0, 0)` is `A1`
[stderr] - `getRange(1, 2)` is `C2`
[stderr] - `getRange(0, 0, 2, 2)` is `A1:B2`
[stderr] - `insertRows(4, 3)` inserts 3 rows starting at spreadsheet row 5
[stderr] - `insertColumns(1, 2)` inserts 2 columns starting at spreadsheet column B
[stderr] 
[stderr] Use numeric coordinates for loops or generated positions. Use A1 notation when the target is fixed and workbook-facing.
[stderr] 
[stderr] ## A1 Notation
[stderr] 
[stderr] Prefer A1 notation for explicit workbook-facing locations:
[stderr] 
[stderr] - `'A1'`
[stderr] - `'A1:B10'`
[stderr] - `'A:A'`
[stderr] - `'1:1'`
