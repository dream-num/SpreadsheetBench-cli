[stderr] `univer` is a spreadsheet engine in the terminal. Use it when an agent needs real workbook semantics: sheets, ranges, formulas, formatting, layout, previews, imports, exports, or versioned workbook state.
[stderr] 
[stderr] Install the CLI with `npm i -g univer-cli`. Update the CLI with `univer update`. The executable is `univer`; `unv` may be available as a short alias.
[stderr] 
[stderr] ## Core Mental Model
[stderr] 
[stderr] Treat workbook-visible state as the source of truth. A successful command summary, package metadata, or an internal manifest does not prove that sheet names, cell values, formulas, formatting, or exported handoff files are correct.
[stderr] 
[stderr] The workbook path is the local identity. Pick one explicit path such as `./budget.univer` and use that path as the CLI target. Do not target workbooks by `unitId`, `sessionId`, manifest ids, or runtime ids.
[stderr] 
[stderr] `.univer` and `.unv` files are CLI operation targets, not agent-editable data stores. Read and write workbook data through public CLI surfaces such as `inspect`, `search`, `pipe`, `run`, `export`, `status`, and `commit`.
[stderr] 
[stderr] Use `univer help` and `univer help <command...>` for exact syntax. For `run` scripts, use `univer help run` and `univer help run <topic>` before relying on unfamiliar APIs.
[stderr] 
[stderr] ## Use When
[stderr] 
[stderr] Use this skill when the task involves spreadsheet or workbook work, especially:
[stderr] 
[stderr] - creating, importing, exporting, or handing off `.xlsx`, `.csv`, `.univer`, or `.unv` files
[stderr] - inspecting workbook shape, sheets, ranges, formulas, formatting, or visible cell state
[stderr] - locating content-defined rows, columns, headers, or cells before editing
[stderr] - making bounded edits to cells, formulas, formatting, charts, shapes, floating images, layout, or sheet structure
[stderr] - streaming rectangular workbook data through shell tools before reading it into context
[stderr] - writing generated matrix data back into a sheet-qualified range
[stderr] - previewing workbook state locally with `univer view`
[stderr] - reading submitted local viewer review comments with `univer view comments`
[stderr] - creating, restoring, resetting, pulling, or syncing local workbook changesets
[stderr] - proving that a workbook-visible mutation or export is correct enough to hand back
[stderr] 
[stderr] ## Default Operating Loop
[stderr] 
[stderr] 1. Pick one explicit workbook path, for example `./budget.univer`.
[stderr] 2. Create or import a workbook first if no `.univer` or `.unv` target exists.
[stderr] 3. Inspect workbook-visible state before deciding where to write.
[stderr] 4. Locate targets from visible headers, values, formulas, or inspected ranges.
[stderr] 5. Choose the smallest public CLI surface that fits the task.
[stderr] 6. Mutate through the CLI, not by editing package internals.
[stderr] 7. Verify changed workbook-visible state with `inspect`, `pipe out`, or another public read.
[stderr] 8. Export only after verification when the user needs a handoff file.
[stderr] 9. After changes have been verified, if the user may need to inspect, audit, or review the final workbook, run `univer view "$WB" --no-open --json` to get a local preview link and include that link in your response.
[stderr] 10. Commit or sync only after verified changes when versioning is part of the workflow.
[stderr] 
[stderr] ## Hard Rules
[stderr] 
[stderr] - Do not read `.univer` or `.unv` internals to infer workbook contents.
[stderr] - Do not write, patch, unzip, rezip, rename internal files, or manipulate workbook package contents.
[stderr] - Do not inspect `manifest.json`, snapshots, mutation logs, or package fragments as a substitute for workbook-visible reads.
[stderr] - Do not guess sheet names, row numbers, formulas, ranges, or changed cells from memory or file metadata.
[stderr] - Do not treat stdout summaries as proof of workbook state. Verify with a workbook-visible read.
[stderr] - Do not invent commands or `run` APIs. Check `univer help` and documented run topics.
[stderr] 
[stderr] Direct package access can corrupt workbooks or teach the agent false state. If the CLI cannot read what you need, diagnose the CLI/runtime path instead of bypassing it.
[stderr] 
[stderr] ## Command Selection
[stderr] 
[stderr] | Need | Prefer |
[stderr] | --- | --- |
[stderr] | Discover exact command syntax | `univer help`, `univer help <command...>` |
[stderr] | Start a workbook package | `univer new` or `univer import` |
[stderr] | Hand back Excel-compatible output | `univer export` |
[stderr] | Understand workbook shape before editing | `univer inspect workbook`, then `univer inspect range` |
[stderr] | Locate content-defined cells | `univer search`, scoped with `--sheet` and/or `--range` when possible |
[stderr] | Stream rectangular data through shell tools | `univer pipe out` |
[stderr] | Write a known rectangular matrix back | `univer pipe in` |
[stderr] | Apply bounded workbook-local logic | `univer run --file` |
[stderr] | Create or maintain workbook charts | `univer run --file` with `univer help run charts` |
[stderr] | Create or maintain workbook shapes and connectors | `univer run --file` with `univer help run shapes` |
[stderr] | Create or maintain workbook floating images | `univer run --file` with `univer help run images` |
[stderr] | Preview readonly workbook state | `univer view --no-open --json` or `univer view` |
[stderr] | Read local viewer review feedback | `univer view comments "$WB" --json` |
[stderr] | Check local versioning state | `univer status` |
[stderr] | Create a local changeset from local mutations | `univer commit --message <message>` |
[stderr] | Discard uncommitted local mutations | `univer restore` |
[stderr] | Reset local unsynced commits | `univer reset --soft HEAD~N` or `univer reset --hard HEAD~N` |
[stderr] | Initialize a local package from an existing remote unit | `univer clone --unit-id <unitID>` |
[stderr] | Pull remote-only changes for a bound package | `univer pull` |
[stderr] | Sync local and remote versioning state | `univer sync` |
[stderr] | Diagnose runtime problems | `univer doctor`, `univer daemon status` |
[stderr] | Prepare a bug report or Univer team support artifact after user authorization | `univer doctor collect` |
[stderr] 
[stderr] Use canonical command help such as `univer help inspect range` and `univer help pipe out`. Top-level help group headings are visual sections only; do not run group-prefixed topics such as `univer help read inspect range`.
[stderr] 
[stderr] ## Execution Results
[stderr] 
[stderr] Treat non-zero exit as failure even when stdout is partially present. Read stderr before changing approach; it usually contains the stable diagnostic code, usage, and retry examples.
[stderr] 
[stderr] Keep data stdout clean in shell pipelines. If diagnostics are needed, capture stderr separately so downstream tools receive only workbook data.
[stderr] 
[stderr] ```bash
[stderr] univer inspect range "$WB" --range 'Sheet1!A1:D20' > ./range.md 2> ./range.err
[stderr] status=$?
[stderr] if [ "$status" -ne 0 ]; then
[stderr]   sed -n '1,80p' ./range.err
[stderr]   exit "$status"
[stderr] fi
[stderr] sed -n '1,40p' ./range.md
[stderr] ```
[stderr] 
[stderr] ## Workflow Recipes
[stderr] 
[stderr] These are verified command shapes. Replace paths, sheet names, and ranges with inspected workbook facts.
[stderr] 
[stderr] ### Create Or Import, Then Inspect
[stderr] 
[stderr] ```bash
[stderr] WB=./orders.univer
[stderr] univer import ./orders.csv "$WB" --json
[stderr] univer inspect workbook "$WB"
[stderr] univer inspect range "$WB" --range 'Sheet1!A1:D4'
[stderr] ```
[stderr] 
[stderr] Use `new` when the task starts from a blank workbook:
[stderr] 
[stderr] ```bash
[stderr] WB=./workbook.univer
[stderr] univer new "$WB" --name "Workbook"
[stderr] univer inspect workbook "$WB"
[stderr] ```
[stderr] 
[stderr] ### Locate Before Editing
[stderr] 
[stderr] Use `search` before editing when the target is defined by visible workbook content:
[stderr] 
[stderr] ```bash
[stderr] univer search "$WB" West
[stderr] ```
[stderr] 
[stderr] Plain text output is one A1 reference per matched cell, which keeps shell pipelines clean. With no
[stderr] matches, stdout is empty and the command still succeeds. Use `--json` when you need match metadata,
[stderr] the matched cell data preview, truncation flags, counts, or the searched scope:
[stderr] 
[stderr] ```bash
[stderr] univer search "$WB" West --sheet Orders --range 'A1:Z200' --json
[stderr] ```
[stderr] 
[stderr] By default, search checks `displayValue`, so formatted values such as dates are searchable by the
[stderr] same strings a user sees in the sheet. Use `--type rawValue` for underlying numeric/string values
[stderr] such as spreadsheet date serials, and `--type formula` for formulas:
[stderr] 
[stderr] ```bash
[stderr] univer search "$WB" 2024-01-01
[stderr] univer search "$WB" 45292 --type rawValue
[stderr] univer search "$WB" SUM --type formula --json
[stderr] ```
[stderr] 
[stderr] Useful narrowing options:
[stderr] 
[stderr] - `--sheet <name>` may be repeated.
[stderr] - `--range <A1>` may be repeated; unqualified ranges require a `--sheet`.
[stderr] - `--case-sensitive` and `--whole-cell` tighten matching.
[stderr] - `--max-results` limits returned matches; truncation is reported on stderr for text output and in JSON fields for `--json`.
[stderr] - `--max-cell-value-length` bounds previewed cell data in JSON.
[stderr] 
[stderr] If `search` fails, read stderr for the diagnostic message before changing approach. If the target is
[stderr] not content-defined, inspect a bounded range and derive the edit boundary from visible headers and
[stderr] sample rows:
[stderr] 
[stderr] ```bash
[stderr] univer inspect range "$WB" --range 'Sheet1!A1:D20'
[stderr] ```
[stderr] 
[stderr] ### Pipe Out Through Shell Tools
[stderr] 
[stderr] Use `pipe out` when the shell can reduce or reshape rectangular data before the agent reads it. Prefer TSV for `awk`, JSON for `jq`, and `--type rawValue` when formatted display text is not safe enough for comparisons.
[stderr] 
[stderr] ```bash
[stderr] univer pipe out "$WB" --range 'Sheet1!A1:D4' --format tsv > ./orders.tsv
[stderr] awk -F '\t' 'BEGIN{OFS="\t"} NR==1 || $2=="West" {print $1,$3}' ./orders.tsv > ./west.tsv
[stderr] sed -n '1,5p' ./west.tsv
[stderr] ```
[stderr] 
[stderr] ### Pipe In Generated Table Data
[stderr] 
[stderr] Write only a known matrix into an explicit, sheet-qualified range. Make `pipe in` the terminal stage of a pipeline unless you intentionally want its success summary downstream.
[stderr] 
[stderr] ```bash
[stderr] univer pipe in "$WB" --range 'Sheet1!F1:G3' --input-format tsv --data-file ./west.tsv
[stderr] univer inspect range "$WB" --range 'Sheet1!F1:G3'
[stderr] univer pipe out "$WB" --range 'Sheet1!F1:G3' --format tsv
[stderr] ```
[stderr] 
[stderr] Verify headers, sample rows, and key columns. Row count alone is weak evidence because shifted columns can still preserve row count.
[stderr] 
[stderr] ### Run A Bounded Workbook Script
[stderr] 
[stderr] Use `run --file` for workbook-native logic that does not fit `inspect`, `search`, `pipe`, or `export`. Check `univer help run` and the relevant `univer help run <topic>` manual before using unfamiliar APIs.
[stderr] 
[stderr] ```bash
[stderr] cat > ./review.js <<'JS'
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sheet1");
[stderr]   if (!sheet) return { success: false, error: "Sheet1 not found" };
[stderr] 
[stderr]   sheet.getRange("I1:J3").setValues([
[stderr]     ["metric", "value"],
[stderr]     ["west_orders", 2],
[stderr]     ["reviewed", "yes"],
[stderr]   ]);
[stderr] 
[stderr]   return { success: true, changedRanges: ["Sheet1!I1:J3"] };
[stderr] }
[stderr] JS
[stderr] 
[stderr] univer run "$WB" --file ./review.js
[stderr] univer inspect range "$WB" --range 'Sheet1!I1:J3'
[stderr] ```
[stderr] 
[stderr] `run` scripts should:
[stderr] 
[stderr] - wrap code in `() => { ... }` or `async () => { ... }`
[stderr] - return a plain object with explicit success or error fields
[stderr] - use explicit workbook, sheet, and A1 range boundaries

[stderr] # Ranges
[stderr] 
[stderr] This topic groups cell and range operations for ordinary `run` tasks.
[stderr] 
[stderr] ## Reading From FRange
[stderr] 
[stderr] Get a range from `sheet.getRange(...)`, then use these reads:
[stderr] 
[stderr] - `getValue() -> any` - get the top-left cell value as the normal displayed value
[stderr] - `getRawValue() -> any` - get the top-left cell raw underlying value
[stderr] - `getValues() -> any[][]` - get all cell values in the range as a 2D array
[stderr] - `getRawValues() -> any[][]` - get all underlying raw values in the range as a 2D array
[stderr] - `getFormulas() -> string[][]` - get formulas in A1 notation
[stderr] - `getA1Notation(withSheet?) -> string` - get the range A1 notation; `withSheet=true` includes the sheet name
[stderr] - `forEach(callback) -> void` - iterate cells in the range
[stderr] - `isMerged() -> boolean` - check whether the range itself is merged
[stderr] - `isPartOfMerge() -> boolean` - check whether the range falls inside a merged region
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sales");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sales" not found' };
[stderr] 
[stderr]   const range = sheet.getRange("A1:C3");
[stderr]   return {
[stderr]     success: true,
[stderr]     a1: range.getA1Notation(),
[stderr]     values: range.getValues(),
[stderr]     formulas: range.getFormulas()
[stderr]   };
[stderr] };
[stderr] ```
[stderr] 
[stderr] ## Writing To FRange
[stderr] 
[stderr] Core writes:
[stderr] 
[stderr] - `setValue(value) -> FRange` - set one value across the target range; if the value starts with `=`, it can also write a formula
[stderr] - `setValues(values) -> FRange` - batch set values from a 2D array
[stderr] - `setFormula(formula) -> void` - set a formula in A1 notation such as `=SUM(A1:B10)`
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sheet1");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sheet1" not found' };
[stderr] 
[stderr]   sheet.getRange("A1").setValue("Total");
[stderr]   sheet.getRange("B2:C3").setValues([
[stderr]     [10, 20],
[stderr]     [30, 40]
[stderr]   ]);
[stderr] 
[stderr]   return { success: true };
[stderr] };
[stderr] ```
[stderr] 
[stderr] ## setValues() Shape Rules
[stderr] 
[stderr] `setValues()` expects a rectangular 2D array whose shape matches the target range:
[stderr] 
[stderr] - one row per worksheet row in the target range
[stderr] - one column per worksheet column in the target range
[stderr] - keep every inner array the same length
[stderr] - use `getRange('A1:C10')` or `getRange(0, 0, 10, 3)` to define the full target shape
[stderr] - `getRange(row, col)` without size only targets a single cell
[stderr] 
[stderr] Correct:
[stderr] 
[stderr] ```javascript
[stderr] sheet.getRange("A1:B2").setValues([
[stderr]   ["Name", "Score"],
[stderr]   ["Ada", 95]
[stderr] ]);
[stderr] ```
[stderr] 
[stderr] Incorrect shape:
[stderr] 
[stderr] ```javascript
[stderr] sheet.getRange("A1:B2").setValues([["Name"], ["Ada", 95, "extra"]]);
[stderr] ```
[stderr] 
[stderr] When writing a single cell, use `setValue()` unless the task specifically benefits from 2D shape handling.
[stderr] 
[stderr] ## Formulas And Async Readback
[stderr] 
[stderr] Formula calculation is asynchronous. This applies to:
[stderr] 
[stderr] - `range.setFormula('=SUM(B1:B10)')`
[stderr] - `range.setValue('=SUM(B1:B10)')`
[stderr] 
[stderr] If you need the calculated result in the same `run`, wait for formula application:
[stderr] 
[stderr] ```javascript
[stderr] async () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Sales");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Sales" not found' };
[stderr] 
[stderr]   sheet.getRange("A1").setFormula("=SUM(B1:B10)");
[stderr]   await univerAPI.getFormula().onCalculationResultApplied();
[stderr] 
[stderr]   return {
[stderr]     success: true,
[stderr]     value: sheet.getRange("A1").getValue()
[stderr]   };
[stderr] };
[stderr] ```
[stderr] 
[stderr] Available formula wait API:
[stderr] 
[stderr] - `univerAPI.getFormula() -> FFormula`
[stderr] - `onCalculationResultApplied() -> Promise<void>` - wait for formula-calculation results to be applied before reading the computed value
[stderr] 
[stderr] ## Merge And Unmerge
[stderr] 
[stderr] Merge APIs:
[stderr] 
[stderr] - `merge(options?) -> void` - merge cells into one block
[stderr] - `breakApart() -> void` - unmerge cells
[stderr] - `mergeAcross() -> void` - merge each row across the selected columns
[stderr] - `mergeVertically() -> void` - merge each column down the selected rows
[stderr] 
[stderr] Typical uses:
[stderr] 
[stderr] - `merge()` for one combined block
[stderr] - `mergeAcross()` to merge each row across the selected columns
[stderr] - `mergeVertically()` to merge each column down the selected rows
[stderr] - `breakApart()` to remove merges
[stderr] - use `merge({ isForceMerge: true })` if you need to clear overlapping merges first
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Report");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Report" not found' };
[stderr] 
[stderr]   sheet.getRange("A1:D1").merge();
[stderr]   sheet.getRange("A3:D4").mergeAcross();
[stderr] 
[stderr]   return {
[stderr]     success: true,
[stderr]     titleMerged: sheet.getRange("A1").isPartOfMerge()
[stderr]   };
[stderr] };
[stderr] ```
[stderr] 
[stderr] ## Clear And Cell Shift Operations
[stderr] 
[stderr] Clear APIs:
[stderr] 
[stderr] - `clear() -> void` - clear the full range
[stderr] - `clearContent() -> void` - clear only content and keep formatting
[stderr] - `clearFormat() -> void` - clear only formatting and keep content
[stderr] 
[stderr] Use `clear()` when the task is to clear the full range. Use `clearContent()` or `clearFormat()` when you only want one part of that behavior.
[stderr] 
[stderr] Cell shift APIs:
[stderr] 
[stderr] - `insertCells(dimension) -> void` - insert cells and shift existing cells in the given dimension
[stderr] - `deleteCells(dimension) -> void` - delete cells and shift remaining cells in the given dimension
[stderr] 
[stderr] Dimension constants:
[stderr] 
[stderr] - `univerAPI.Enum.Dimension.ROWS`
[stderr] - `univerAPI.Enum.Dimension.COLUMNS`
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Queue");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Queue" not found' };
[stderr] 
[stderr]   sheet.getRange("B2:C3").clear();
[stderr]   sheet.getRange("D2:D10").insertCells(univerAPI.Enum.Dimension.ROWS);
[stderr] 
[stderr]   return { success: true };
[stderr] };
[stderr] ```

[stderr] ## AutoFill
[stderr] 
[stderr] Use `autoFill()` when a correct seed pattern already exists and the workbook should propagate it.
[stderr] 
[stderr] - `autoFill(destRange, fillType?) -> Promise<void>` - propagate from the source range into a larger destination that includes the source
[stderr] 
[stderr] Notes:
[stderr] 
[stderr] - `destRange` must include the source range
[stderr] - `fillType` can be `'SERIES'` (default) or `'COPY'`
[stderr] - this method is async; use `await`
[stderr] 
[stderr] Example:
[stderr] 
[stderr] ```javascript
[stderr] async () => {
[stderr]   const workbook = univerAPI.getActiveWorkbook();
[stderr]   const sheet = workbook.getSheetByName("Series");
[stderr]   if (!sheet) return { success: false, error: 'Sheet "Series" not found' };
[stderr] 
[stderr]   const source = sheet.getRange("A1:A2");
[stderr]   const dest = sheet.getRange("A1:A10");
[stderr]   await source.autoFill(dest);
[stderr] 
[stderr]   return { success: true, values: dest.getValues() };
[stderr] };
[stderr] ```
