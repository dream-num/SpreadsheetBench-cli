# 22 - task 31202

## 题目要求

在 payroll 表 `NOMINA!J2:J47` 自动更新 `DEBT`：同一 worker 延续上一周 debt，并根据本周 `DEDUCTIONS` 与 `ADDITIONS` 调整。

## 评测差异

优先 run：`.runs/univer-agent/codex-gpt-5-5-verified400-all-20260526-231834`。

按 openpyxl `data_only=True` 比较 `J2:J47`，共有 2 个值差异：

- `NOMINA!J35`: output `-1500`，golden `1500`
- `NOMINA!J45`: output `-1000`，golden `1000`

上下文显示 row 35 是 `JESUS MAGAÑA`，`DEDUCTIONS=0`、`ADDITIONS=1500`，golden debt 为 `1500`；row 45 同 worker，`DEDUCTIONS=500`、`ADDITIONS=0`，golden 从前值 `1500` 调整到 `1000`。

## agent 解题过程与卡点

agent 写入公式：

`previous_debt + G(row) - H(row)`

其中表头显示 `G=DEDUCTIONS`、`H=ADDITIONS`。这会让 addition 使 debt 下降、deduction 使 debt 上升，正好与 golden 的符号方向相反。正确口径应是延续上一 debt 后 `- DEDUCTIONS + ADDITIONS`。

agent 做了样本验证，但样本选了 `J2/J24/J47`，没有覆盖有非零 `DEDUCTIONS` 或 `ADDITIONS` 的关键行，所以未发现符号错误。

## 归因分类

agent 自身题意理解/推理错误：把 deductions 与 additions 对 debt 的符号方向反了。验证也不足，没有抽查非零调整行。

## 是否建议写矩阵备注

建议写矩阵备注：`agent 公式符号反向，写成 previous + deductions - additions；golden 需要 previous - deductions + additions，导致 J35/J45 符号错误。`
