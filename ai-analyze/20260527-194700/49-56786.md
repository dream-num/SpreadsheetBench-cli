## agent 解题过程与卡点

日志显示 agent 先检查了题目中已有示例公式，如 `C70 = AVERAGE(B24:B69)`、`C80 = AVERAGE(B29:B79)`，随后判断“previous 365 days”应排除当前行，只取前序记录。它写入了 `fill_rolling_average.js`，在 `C4:C200` 批量写 `IFERROR(AVERAGEIFS(...ROW()-1...), "")`，并用 `C70/C80/C99/C200` 的自设预期做验证。

卡点是边界语义判断错误：题目和 golden 要的是包含当前日期记录的 365 天窗口，且 Table 公式会包含同一日期的多行；agent 将“previous”解释为严格早于当前行。验证也只对照了旧示例的少量显示值，没有与完整目标公式或全范围结果核对。
