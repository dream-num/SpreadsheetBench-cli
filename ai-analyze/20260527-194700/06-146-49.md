- output `G1:H1`：`ALEXINE / ALEXINS`
- golden `G1:H1`：`ALEXINS / ALEXINE`
- output `G2:H2`：`AREOLAE / AREOLAS`
- golden `G2:H2`：`AREOLAS / AREOLAE`

后续 65 行均为同类反列。

## Agent 解题过程分析

agent 遍历包含 `S` 的词 `sWord`，把 `S` 全部替换成同一个元音得到 `vowelWord`，如果 `vowelWord` 存在，则输出 `[vowelWord, sWord]`。golden 期望 `[sWord, vowelWord]`。

agent 的 pair 发现、去重、数量和排序基本匹配；失败集中在列映射方向。stdout 中也明确报告 first pair 是 `ALEXINE / ALEXINS`，说明它验证的是自己的列顺序，而不是题目/golden 方向。
