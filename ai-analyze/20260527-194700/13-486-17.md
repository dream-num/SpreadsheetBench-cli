# 13 - task 486-17

## 题目要求

将 A 列中形如 `0yyyymmdd` 的日期编号转成带空格的 `yyyy mm dd`，从 `B2` 开始写入，不加 header。`answer_position` 为 `'Blad1'!B2:B130`。

## 评测差异

目标 run 本次评测失败。按 `data_only=True` 比较 `Blad1!B2:B130`，仅 3 个值差异：

- `B99`: output `None`，golden `'atum  v er'`
- `B100`: output `None`，golden `'atum  v er'`
- `B101`: output `None`，golden `'atum  v er'`

检查 init/golden 可见 `A99:A101` 都是文本 `Datum verzending`。golden 对这些非日期文本仍按固定字符串位置切片，得到 `atum  v er`；agent 则把非数字来源留空。

## agent 解题过程与卡点

agent 的 `transform_case_1.js` 对每行读取 `A{row}`，先 `replace(/\D/g, "")` 提取数字；只有 9 位且以 0 开头或 8 位数字时才生成 `yyyy mm dd`，否则写空字符串。它还专门检查了 `95:105` 行，并在日志结论中说明“Rows where the source contained repeated header text were left blank”。

卡点是验证过度过滤：agent 认为任务对象是“numbers in cells that represent dates”，所以跳过重复 header 文本；但评测 golden 按宏式固定字符切片处理所有行，包括异常 header 行。

## 归因分类

混合归因：agent 自身边界处理与 golden 不一致，同时存在数据/题目歧义。题面说是日期数字列表，但数据中夹有重复 header；golden 期望对 header 也做字符串切片，agent 选择留空。
