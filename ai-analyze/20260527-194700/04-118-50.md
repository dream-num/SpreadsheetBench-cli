# 118-50 错题调查

## 题目要求与 answer_position

- 选用 run：`codex-gpt-5-5-verified400-all-20260526-231834`
- 题目要求：按字母顺序排序 A 列名称，并查找指定词形转换配对；结果放在 C/D，D 为原词，C 为转换词；按后缀组顺序 `ING, ERS, ATE, EST, ONE, IER, ILY` 输出；不要添加额外标题或格式。
- `answer_position`：`'Sheet1'!C2:D5000`

## 评测差异摘要

按正式评测口径比较，`Sheet1!C2:D5000` 共 9998 个单元格，24 个值不同。差异表现为结果整体下移一行：

- output `C1:D1` 仍保留 init 中的 `EARTHPEA/HEARTPEA`。
- output 从 `C2:D13` 写入 12 对结果。
- golden 从 `C1:D12` 写入 12 对结果；由于评测只看 `C2:D5000`，golden 的 `C2:D12` 是 output 的第 2 到第 12 对，导致 `C2:D13` 全部错位。

样例：

- `Sheet1!C2:D2`：output `TABORING/ABORTING`，golden `TAVERING/AVERTING`
- `Sheet1!C6:D6`：output `DREADING/READDING`，golden `TABORERS/ABORTERS`
- `Sheet1!C13:D13`：output `HEARTILY/EARTHILY`，golden 空白

## Agent 解题过程分析

agent 严格按 `answer_position` 从 `C2:D5000` 清空并写结果，且没有改 `C1:D1`。它的输出列表内容本身与 golden 的结果列表一致，但起始行不一致。stdout 也明确写“`C2:D13` contains the 12 transformation/original pairs”。

这里存在数据/标注矛盾：`answer_position` 是 `C2:D5000`，但 golden 把第一对结果放在 `C1:D1`，且正式评测忽略 `C1:D1` 后自然要求 output 在 `C2` 对齐 golden 的第二对结果。agent 按题面限制执行，反而与 golden 错位。
