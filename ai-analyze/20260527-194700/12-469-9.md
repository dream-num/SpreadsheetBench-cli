## 题目要求

从 Column C 的金额中分离 debit 与 credit，在 H 列新增 `Debits`，I 列新增 `Credits`，写入绝对值；没有值时保持空白。`answer_position` 为 `H1:I10`。

## 评测差异

目标 run 本次评测失败。按 `data_only=True` 比较 `Sheet1!H1:I10`，共 18 个值差异，核心模式是 H/I 两列写反：

- 正数行如 `C2=4543.19`：output 写到 `I2`，golden 期望 `H2`
- 负数行如 `C5=-6.9333`：output 写到 `H5`，golden 期望 `I5`
- 同样的反向映射出现在 `H2:I10` 的所有金额行

表头 `Debits` / `Credits` 本身正确。

## agent 解题过程与卡点

agent 的 `case_1_split_debits_credits.js` 读取 `C2:C10`，清空 `H1:I10`，写入表头后按符号分流：`amount < 0` 写 H 列并标记 debit，正数写 I 列并标记 credit。日志中最终验证也明确写道“positive Column C amounts were placed as absolute values in Credits, negative amounts as absolute values in Debits”。
