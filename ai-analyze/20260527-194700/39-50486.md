## 题目要求

在 `Sheet1!A2:A5` 根据对应行 `CHEP` 或 `LOSCAM` 列是否有数值，显示 pallet type。评测只比较 `A2:A5` 的 `data_only=True` 值。

矩阵备注：对应行备注为空。

## 评测差异

正式 run `codex-gpt-5-5-verified400-all-20260526-231834`，runner `ok`，评测 `FAIL`。

差异全部是大小写：

- `A2`: output `'Chep'`，golden `'CHEP'`
- `A3`: output `'Chep'`，golden `'CHEP'`
- `A4`: output `'Loscam'`，golden `'LOSCAM'`
- `A5`: output `'Loscam'`，golden `'LOSCAM'`

golden 公式使用表头：

`=_xlfn.IFNA(INDEX($C$1:$D$1,MATCH(99^99,$C2:$D2)),"")`

所以结果继承了 `C1:D1` 的大写标题。

## agent 解题过程与卡点

agent 读取 skill，检查 `Sheet1!A1:D5`，确认 `C2:C3` 有 CHEP 数值、`D4:D5` 有 LOSCAM 数值。随后写入显式字符串 cell model：`Chep`, `Chep`, `Loscam`, `Loscam`，并用 `getCellDatas()` 验证后导出。

卡点是 agent 按 prompt 中引号文字 `Chep`/`Loscam` 写 title case 静态文本，而没有使用现有表头 `CHEP`/`LOSCAM` 或 golden 的公式方式。评测是大小写敏感值比较，因此失败。

## 归因分类

题目/数据期望存在大小写歧义：prompt 明说 `Chep`/`Loscam`，但 workbook header 与 golden 为 `CHEP`/`LOSCAM`。按评测结果看，agent 未对齐 workbook/golden 的表头大小写。
