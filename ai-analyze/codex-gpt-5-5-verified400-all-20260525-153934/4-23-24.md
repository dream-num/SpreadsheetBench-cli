## 任务理解

题目要求如果 `A` 列的单词匹配 `I` 列任意单词，就像手工选中 `A:E` 后 `Ctrl+-` 上移一样，删除该单词及其 `B:E` 关联详情。目标影响范围是 `A1:E1102`。

## agent 解题过程

agent 检查了 `Sheet1!A1100:E1110`、`Sheet1!A1098:I1106`，又用 `univer run` 探测 `getCellDatas()`。核心脚本读取 `A1:E1102` 和 `I1:I3707`，按 `A` 列是否在 lookup 集合中决定整行保留或删除，然后把保留行整体写回 `A:E`，尾部清空。

最终 output 可被 openpyxl 读取。`A1:E1102` 内共有 78 个差异，主要是输出保留了 `B` 或 `C` 列中的零散字符，而 golden 中对应单元格为空：

- `C8`: output 为 `"s"`，golden 为空；该行其他关键值为 `["APLASIAS", null, *, 34426, "AAAILPSS"]`
- `C24`: output 为 `"elns"`，golden 为空
- `B27`: output 为 `"p"`，golden 为空
- `C34`、`C35`、`C49` 等多处 output 为 `"s"`，golden 为空

抽查 input 可见这些字符原本存在于未删除行中；agent 整行保留导致它们残留，而 golden 期望清掉这些关联详情列。

- 删除类题目验证时应检查目标范围内所有列，而不是只验证匹配词是否消失和尾部是否清空。
