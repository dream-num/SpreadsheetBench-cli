## 卡点分析

- 文本精确性问题：agent 忽略了源表头 `CHEP` / `LOSCAM` 的大小写，改用题面中的 `Chep` / `Loscam`。
- 输出类型问题：golden 用公式引用表头，因此可随 C/D 列变化；agent 写死静态文本。
- 验证不足：只验证了语义标签，没有验证大小写和公式文本。
- 无命令失败、无导出异常。

## 归因分析

- agent 自身题意理解/推理/验证问题：主要原因。未保持 workbook header 的精确文本和公式化输出。
- 数据/题目歧义或其它问题：次要原因。prompt 明写 title-case，但 golden 期待 header 原文 uppercase。
- 未发现 `univer-cli` 命令或 API 问题。

## 改进建议

- 此类“根据对应列输出标签”题应优先引用或复制表头文本，而不是手写大小写。
- 如果目标列原本是公式列或题目说“Configure column”，优先写公式而非静态值。
- 验证时比较 exact string，包括大小写、空格和公式/值类型。
