## 卡点分析

agent 把“empty cells should show a hyphen instead of a zero”理解为写入字符串 `"-"`。golden 的实际做法是保留数值 `0.0`，通过数字格式显示 `-`。这导致值类型从 number 变成 string，且后续公式/数值语义丢失。agent 的验证只确认 visible/raw 局部值，没有对照 number format。

## 归因分析

- agent 自身题意理解/验证问题: 将显示要求实现为字符串，而不是数值 + 数字格式；同时没有验证 number format 和样式。
- skill 指引/API 文档不清: 当前通用提示强调了 dates/percent/currency 的 number format，但对“零显示为 hyphen、负数红色”这类自定义 number format 没有足够显式的操作策略，agent 转向写字符串。
- 未发现 `univer-cli` 命令/API bug；run 和 export 都成功。

## 改进建议

- 对“显示为 -/红色负数”的要求，应优先使用 number format，例如 `#,##0;[Red]\-#,##0;\-`，不要把 0 写成字符串。
- 验证需同时读取 `getCellDatas()` 或导出后用 openpyxl 检查 `value/data_type/number_format/font_color`。
- 对跨 sheet 聚合任务，最终验证应抽查至少一个零值、一个负值、一个新增行和一个原有行。
