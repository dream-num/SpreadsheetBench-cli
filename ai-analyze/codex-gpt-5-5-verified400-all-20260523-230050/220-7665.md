# 220-7665

## 题目概览

- run-id：`codex-gpt-5-5-verified400-all-20260523-230050`
- 题目号：`7665`
- 类型：Cell-Level Manipulation
- answer_position：`Q2:V2`
- 任务要求：把 `Sheet1` 中 H 列竖向数字去重、排序后横向放到 `Q2:V2`，并以公式方式完成。

## 评测结论

评测为失败。Docker 任务本身正常结束，`docker.timing.json` 显示 `returncode=0`、未超时、耗时约 93 秒。失败来自最终 `output.xlsx` 的目标区域与 golden 不一致：`Q2` 有公式且缓存值为 11，但 `R2:V2` 在导出的 xlsx 中为空。

## 解题过程分析

日志显示 agent 先读取 `univer-cli` skill，然后执行：

- `univer inspect workbook`
- `univer pipe out ... H1:H20 --format json`
- `univer run ... --file /task/work/case_1_formula.js`
- `univer inspect range ... Q2:V2`
- `univer pipe out ... Q2:V2 --format json`
- `univer pipe out ... Q2:V2 --format json --type formula`
- `univer export ... output.xlsx`

实际脚本只在 `Q2` 写入一个动态数组公式：

```js
sheet.getRange("Q2").setFormula('=TRANSPOSE(SORT(UNIQUE(FILTER(H2:H20,H2:H20<>""))))');
```

agent 在 stdout 中声称已验证 `Q2:V2` 为 `11, 22, 33, 44, 66, 77`，说明 Univer 运行态里能看到溢出结果。但导出的 xlsx 并没有把溢出区域物化或保留为可评测结果。

## output vs golden 差异

用 `openpyxl` 对比 `data/spreadsheetbench_verified_400/outputs/univer_agent_gpt-5.5/1_7665_output.xlsx` 与 `data/spreadsheetbench_verified_400/spreadsheet/7665/1_7665_golden.xlsx`：

- `Q2:V2` 共 6 个单元格，缓存值差异 5 个：`R2:V2` output 为 `None`，golden 分别为 `22, 33, 44, 66, 77`。
- formula 差异 6 个：output 只有 `Q2` 一个动态数组公式；golden 在 `Q2:V2` 每格都有兼容公式，例如 `Q2` 为 `=IFERROR(SMALL($H$2:$H$18,COUNTIF($H$2:$H$18,"<="&P2)+1),"")`。
- 数字格式无差异；样式存在字体颜色编码差异，但不是主要失败点。
- sheet 结构：output/golden/init 均只有 `Sheet1`；未发现 answer 区域外污染。

## 卡点分析

- agent 依赖动态数组溢出公式，只写入 `Q2`，没有写入 `R2:V2` 的公式或静态结果。
- agent 的验证停留在 `.univer` 运行态，没有在导出的 `output.xlsx` 上重新验证 `Q2:V2`。
- 日志开头有一次非致命模型列表刷新超时：`failed to refresh available models`，但后续正常执行，不是本题失败原因。

## 归因分析

- agent 自身题意理解/推理/验证问题：主要原因。题目和评测目标是 `Q2:V2` 的最终 xlsx 结果，agent 没有验证导出后的 xlsx，且没有考虑动态数组公式在导出/评测中的兼容性。
- univer-cli 命令或 API 问题：次要可疑点。证据是 `univer run` 后运行态验证看到完整溢出值，但 `univer export` 后 openpyxl 只看到 `Q2` 缓存值，`R2:V2` 为空，说明动态数组溢出结果没有可靠落到导出文件。

## 改进建议

- 对动态数组公式任务，优先写入评测区域内每格可见的兼容公式，或在导出后读取 `output.xlsx` 验证目标区域缓存值。
- prompt/skill 可补充：不要把 `.univer` 运行态溢出结果等同于导出 xlsx 中的可评测结果；动态数组尤其要导出后复查。
- 若确认 `univer export` 不保存动态数组 spill，可在 `issue/` 记录一个通用 export 兼容性问题。
