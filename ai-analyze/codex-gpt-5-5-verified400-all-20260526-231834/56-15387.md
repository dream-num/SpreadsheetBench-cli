## 结论

output 存在，但 `Sheet1!A14` 的 `data_only=True` 值缺失。agent 写入 `A13` 动态数组公式 `=TRANSPOSE(FILTER($B$3:$F$3,$B$1:$F$1=0))`，Univer 验证时显示 spill 为 `A`、`D`，但导出的 xlsx 用 openpyxl 读取时只有 `A13="A"`，`A14=None`。这是疑似动态数组 spill 缓存/导出问题。

## 证据与复现

- `prompt.md`: `answer_position=A13:A14`。
- `docker.timing.json`: `status=finished`, `returncode=0`, `duration_seconds=77.082`。
- `openpyxl data_only=True`:
  - golden `A13="A"`, `A14="D"`。
  - output `A13="A"`, `A14=None`。
- `data_only=False`: output 仅 `A13` 有 `=TRANSPOSE(FILTER(...))`，`A14` 无公式/缓存；golden 是数组公式 spill。
- 复现材料见 `repro/15387/`。

从日志看 agent 的公式选择符合题意，验证也覆盖了目标范围。但导出的 xlsx 缓存没有保留第二个 spill 值。

## 卡点分析

- 主要卡点是导出后的动态数组 spill 缓存丢失，而不是 agent 没写公式。
- agent 没有在导出后的 xlsx 上用 openpyxl 或其他真实评测口径复核，因此未发现 `A14` 缺失。
- 没有范围外污染；差异只在 spill 的第二个单元格。
- 该现象类似动态数组/FILTER 导出缓存类问题，但本题矩阵备注中未记录为已知 issue。
