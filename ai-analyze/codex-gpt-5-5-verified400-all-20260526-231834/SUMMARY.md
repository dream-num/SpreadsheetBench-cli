## 归因汇总

- agent 自身题意理解/推理/验证问题是主体，占绝大多数保留报告。常见模式是列方向反、边界/表头处理错、排序块结构误判、只抽样验证未覆盖失败行、把显示格式当成真实值。
- `univer-cli` API/skill 指引不清的候选主要是 `02-23-24`：`getCellDatas()` 稀疏 cell model 与 `setValues()` 矩形写回约束容易误用。建议在 skill 中明确“写回大范围前先构造完整矩形或清空目标范围”。
- 明确疑似 `univer-cli`/导出 bug 目前只有 `56-15387`：Univer 内部验证动态数组 spill 为 `A`,`D`，导出 xlsx 后 openpyxl 只读到 `A13="A"`, `A14=None`。最小复现材料在 `repro/15387/`。
- 数据/题目歧义或评测口径敏感题包括 `46-49036`, `55-13284`, `57-32023`, `69-56915`。这些不一定是 CLI bug，但需要在 prompt/agent 策略里强调最终以 `data_only=True` 的真实 `cell.value` 为准。

2. 针对 `56-15387` 使用 `repro/15387/check_answer_range.py` 继续做最小复现，确认是否属于动态数组 spill 导出缓存缺失。
