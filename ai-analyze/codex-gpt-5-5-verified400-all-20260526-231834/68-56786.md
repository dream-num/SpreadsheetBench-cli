# 68-56786

## 结论

该题 FAIL 是 rolling average 公式排除了当前行，并且对相同日期处理与 golden 不一致。按 `data_only=True` 比较 `Sheet1!C4:C200`，0/197 个单元格一致。

golden 公式使用 Excel Table 结构化引用，条件包含当前行：`Date <= current date` 且 `Date >= current date - 365`。agent 使用 `$B$4:INDEX($B:$B,ROW()-1)` 和 `$A$4:INDEX($A:$A,ROW()-1)`，只统计当前行之前的数据。

## 证据与复现

- prompt：创建前 365 天动态范围 rolling average，数据不是每天都有；`answer_position=C4:C200`。
- `C4` output 空，golden `6.166666667559182`；golden 对 2009-01-30 的两条记录取均值。
- `C5` output `1.5000000013969839`，golden 仍为 `6.166666667559182`；说明 golden 包含同日期全部行，而 agent 只看前一行。
- agent 公式样本：`=IFERROR(AVERAGEIFS($B$4:INDEX($B:$B,ROW()-1),$A$4:INDEX($A:$A,ROW()-1),">="&A5-365,$A$4:INDEX($A:$A,ROW()-1),"<="&A5),"")`。
- golden 公式样本：`=AVERAGEIFS(Table1[Beans Counted],Table1[Date],"<="&Table1[[#This Row],[Date]],Table1[Date],">="&Table1[[#This Row],[Date]]-365)`。
- 范围外检查：无 answer_position 外值/公式变更。

## 解题过程分析

agent inspect `A1:C20`、`A20:C105`，pipe out `A20:C105`，查 `run ranges/formulas` help，写 `/task/work/fill_rolling_average.js`。脚本清空 `C4:C200`，写公式；第 4 行特殊写 `=""`。随后 inspect `C4:C10`、`C198:C200`、`C68:C72`，导出 output。

它没有检查相同日期重复记录，也没有验证 C4/C5 的首行边界。

## 卡点分析

- 边界错误：rolling window 应包含当前日期所有记录，agent 只看当前行之前。
- 表格语义遗漏：prompt 希望 Table 自动扩展，golden 使用结构化引用；agent 写普通范围公式。
- 验证不足：inspect 了 C4:C10 但没有发现首行空值与 expected 不合理。
- 无环境/网络/认证问题。

## 归因分析

归因分类：agent 自身题意理解/推理/验证问题。

不是 CLI bug：公式按 agent 写法计算，导出成功。失败来自窗口包含规则错误。

## 建议

- rolling average 应明确“包含当前行/当前日期还是仅 previous rows”；本题应包含当前日期。
- 对重复日期数据，验证 C4/C5 这种最小边界样本，比只看中间行更关键。
