本 workbook 的 header 是通用字母 `A` 到 `V`。agent 按相同 header 直接复制 source `E` 到 destination `E`，但本题期望 destination `E` 为对应发票值；source `E` 在 `cdnr` 中并不是该值，结果写成了 `C`。

## 卡点分析

- agent 机械执行“按相同 header text 对齐”，但没有验证 generic header `A/B/C...` 下的实际业务列语义。
- 只重点验证了 `L/M` 负数金额和首尾列，漏查 `E` 这类非金额但关键的数值列。
- answer_position 的 sheet 名含逗号，日志中曾使用未引用范围 `b2b, sez, de!A1:V10`；后续脚本用 sheet name API 成功，未造成最终失败。
