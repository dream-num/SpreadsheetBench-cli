# 42-48643

## 结论

该题失败是 agent 把空 deposit 年份输出为空，而 golden 要求累计财富继续沿用前一年总额。`answer_position` 是 `H2:H40`。`H2:H4` 值正确，`H5:H40` output 为 `None`，golden 都为 `4719.342`。

agent 的公式是 `=IF(Brow="","",(Brow+N(Hprev))*(1+Crow))`，遇到空 `B` 就返回空。golden 公式是 `=IF(ROW(Brow)=2,Frow,(Hprev+Brow)*(1+Crow))`，Excel 中空 `B/C` 参与运算时相当于 0，因此从 H5 起持续保留 H4 的累计值。

## 解题过程分析

agent 通过 inline `univer run --code` 检查 `A1:H5`、`E2:F4` 公式和值，然后直接在 `H2:H40` 写累计公式。它等待计算，回读 `H2:H5` 和 `H40`，最后导出。stdout 明确说“blank deposit rows left blank”。

这说明它不是导出或计算失败，而是业务规则理解错误：它认为没有 deposit 的年份不应显示累计值。

## 卡点分析

- 业务理解错误：财富总额是状态量，空 deposit 年份仍应保留上一年累计总额，而不是空。
- 验证不足：只把 `H2:H4` 的正确值当作成功证据，还把 blank rows left blank 当成合理行为，没有对照目标公式语义。
- 样式差异明显：golden 使用欧元格式，output 是 General；正式评测不计样式，但说明 agent 未保留目标格式。

## 归因分析

- agent 自身题意理解/推理/验证问题：主要原因。

## 建议

累计余额/财富类题要区分“本期新增为空”和“累计总额为空”。验证应覆盖第一个空输入行以及最后一行，确保状态是否按预期延续。
